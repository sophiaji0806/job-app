# 求职工作台（Job Portal）

个人求职助手：素材库 / 知识库 / 简历 / 投递进度 / 网申助手 一站式本地工作台。

- 数据全部存在**本机** `data/store/*.json`，不上传任何服务器。
- AI 功能只用**你自己填的 API Key**（默认按 DeepSeek 配置，任意 OpenAI 兼容接口都行）。
- 仓库里出现的经历、简历、公司名（张三 / 示例公司 / zhangsan@example.com）都是**示例模板**，首次使用请替换成你自己的。

## 前置要求

- **Node.js 18+**（终端跑 `node -v` 能打印版本即可）
- 一个 OpenAI 兼容的 API Key（去 <https://platform.deepseek.com> 注册即可拿到；不填也能用，但 AI 相关的功能不可用）

## 启动

方式一：双击 `start-job-app.bat`（自动启动服务并打开浏览器）。

方式二：命令行

```bash
npm install      # 只有第一次需要
node server.js
```

浏览器打开 <http://localhost:3000>。服务跑在 3000 端口，窗口别关。

## 第一次使用：把自己的经历导进来

### 第 1 步：配置 API Key

1. 打开 <http://localhost:3000>，点右上角 **⚙ 设置**。
2. 填 API Key；Base URL 默认 `https://api.deepseek.com`；模型默认 `deepseek-chat`。
3. 点 **🔌 测试连接** 确认能通，再点「保存」。

Key 存在本机 `config.json`，不会传给任何第三方。

### 第 2 步：把经历写进「① 个人素材库」

「个人素材库」页有三块：目标岗位方向、职业方向推荐、**个人经历库**。前两块是给你参考的方向卡片（示例数据，可以改成自己的目标），真正要填的是**经历库**。

经历库初始是**空的**（示例经历不在公开仓库里）。两种填法：

**方式 A：手动添加（最直接）**

点 **＋ 手动添加经历**，填六个字段：

| 字段 | 填什么 | 例子 |
|---|---|---|
| 标题 | 一条经历一句话概括 | 信贷风险识别与预警 |
| 阶段 / 来源 | 时间 + 公司/行业，或来自哪个文件 | 示例公司 2023-2026 · 银行业 |
| 方向标签 | 这条经历能投哪几类岗位，逗号分隔 | 通用, 财务BP, 风控 |
| 方向写法 | **每个方向一行**，格式 `方向 \| 描述` | `通用 \| 完成 XX 笔审阅，识别 XX 风险` |
| 关键词 | 面试官会搜的词 | ECL, IFRS9, 五级分类 |
| 量化成果 | 数字成果，逗号分隔 | 3 个月, 5 张报表 |

要点：**同一条经历按不同岗位写不同版本**（「方向写法」每行一个方向），投财务岗和投风控岗时点「切换方向写法 ▸」就能切换措辞，不用重写。

**方式 B：让 AI 访谈挖掘（更省事，需要 API Key）**

点 **💬 向我提问挖掘经历**，AI 会逐题问你（当时做了什么、规模多大、结果如何），你回答问题，它帮你整理成上面的结构化经历。适合「想不起来自己做过什么」的时候。

> 两种方式存的是同一份数据：`data/store/material.json`，纯文本，随时能改、能备份。

### 第 3 步：从经历生成「② 知识库」

回到经历卡片，点 **＋加入知识库**，AI 会把这条经历展开成「面试会被问到的专业知识点 + 逐句代码示例」。也可以点「➕ 新建空白知识点」自己写。

### 第 4 步：生成「③ 简历 · 机会库 · 面试」

这个页里有 7 个子标签：

1. **简历排版**：内置中 / 繁 / 英三套版式（内容是示例，点任意文字直接改）。改完就是你的基础简历。
2. **JD 工作台**：把目标岗位的 JD 原文粘进来（或从机会库载入）。
3. **定制简历**：基于「经历库 + 基础简历 + 这条 JD」拼好一段提示词，点复制 → 粘贴到 **Claude Code** 里跑 → 生成的定制简历再粘回这里存进简历库。
4. **Cover Letter**：同样的方式生成求职信。
5. **简历库**：所有版本存档；也支持导入已有 PDF 简历。
6. **机会库**：见第 5 步。
7. **面试练习**：按岗位生成面试题，做题、对答案。

### 第 5 步：机会库 + ④ 投递进度

「机会库」支持三种导入方式：

- **方式 A：Excel 一键更新** —— 在 `job-app` 的**同级目录**建一个 `机会汇总` 文件夹，把岗位 Excel 丢进去（表头需含「公司名称」或「公司」列），回工作台点「↻ 一键更新」，后端解析 `公司/岗位/类型/地点/截止日期/链接` 各列。文件夹路径定义在 `server.js` 第 17 行的 `OPPORTUNITIES_DIR`，想放别处改这一行即可。
- **方式 B：网页表格 / 飞书 / QQ 笔记** —— 点「复制浏览器取表代码」→ 在已登录的页面按 F12 打开控制台粘贴回车（表格自动进剪贴板）→ 回工作台点「粘贴导入」→「解析并导入」。
- **方式 C：手动** —— 从 Excel 选中表格区域（含表头）复制，直接粘到输入框。

导入后在「④ 投递进度」里跟踪每个岗位从投递到 offer 的全流程。

### 第 6 步：⑥ 网申助手 + Chrome 扩展（可选）

先在「⑥ 网申助手」里维护一份**字段档案**（姓名、电话、邮箱、学校、公司、岗位等），扩展读它来自动填表。

扩展安装：Chrome 打开 `chrome://extensions` → 右上角开「开发者模式」→「加载已解压的扩展程序」→ 选 `extension/` 文件夹 → 保持 `node server.js` 运行 → 打开任意网申页，右下角出现 ◈ 球即生效。

**扩展只填不提交**，填过的字段有蓝色描边，复核后自己点提交。

## 目录结构

```
job-app/
├── server.js            # Express 后端（含 token 加固、AI 问答生成、投递进度接口）
├── public/              # 前端单页应用（app.js / index.html / styles.css）
├── extension/           # Chrome 网申助手扩展（MV3）
│   ├── manifest.json
│   ├── background.js    # 代理本机请求、持令牌
│   └── content.js       # 字段识别/填充/问答生成
├── data/
│   ├── store/           # 全部数据：material / knowledge / jobs / resumes /
│   │                    #   apply / tracker / career / recs / cv / interview
│   ├── seed/            # 种子数据（career / recs；material 需自己填）
│   ├── token.txt        # 本机接口令牌（服务自动生成，勿外传）
│   └── uploads/         # 上传的图片/附件
├── config.json          # API Key 配置（含密钥，勿外传/勿提交）
├── package.json
├── start-job-app.bat    # 一键启动
└── node_modules/
```

## 数据备份

所有数据都在 `data/store/*.json`（纯文本）。备份/迁移：整个 `job-app` 文件夹拷走即可，`node_modules` 可重装（`npm install`）。

## 常见问题

- **经历库是空的？** 公开仓库不含个人经历数据，按「第 2 步」自己添加即可。
- **AI 功能报错 / 没反应？** 先去「设置」点「🔌 测试连接」；确认 Key 有效、余额充足。
- **端口被占？** 改 `server.js` 里的端口号，或先关掉占用 3000 端口的程序。
- **扩展没出现 ◈ 球？** 确认 `node server.js` 在跑，然后刷新网申页面。
